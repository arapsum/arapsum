I’m a software developer based in Nairobi, Kenya. I build software where solid systems work and usable product design meet, from Rust services and data models to desktop tools and web applications.

## What I build

- **Backend systems and authentication** with Rust, Axum, SQLx, PostgreSQL, Redis, JWT, tracing, and OpenAPI.
- **Operational products** for commerce, supply chains, finance, and other domains that need clear workflows, roles, and trustworthy data.
- **Native and terminal tools** with Iced, Ratatui, and Rust, including editors, media utilities, parsers, and Unix-inspired CLIs.
- **Full-stack interfaces** with TypeScript, React, TanStack, SvelteKit, Astro, and Tailwind CSS.
